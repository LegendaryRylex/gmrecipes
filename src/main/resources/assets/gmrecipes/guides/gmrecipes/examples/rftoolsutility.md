# RFTools Utility

Spawner recipes show the three matter slots with the amount each contributes, an arrow to the mob's spawn egg, and the RF cost per spawn; an empty third slot cycles through the yield-tagged items. Syringe recipes show the shaped crafting grid with the mob-filled syringe, the resulting module and the mob's spawn egg.
