# Just Dire Things

Goo spreading shows the block to convert, the goo tiers able to do it and the block it becomes, with the time it takes. Tagged variants cycle through every block in the tag. Fluid transmutation shows the fluid, the item thrown in and the fluid that results. Tool ability upgrades and paxel smithing show their template, base and addition.
