# Recipe Examples

One worked example of every recipe type a mod registers, picked from the recipes actually loaded in
this world. A box that draws is a working renderer; a red *Couldn't find a handler for recipe* names
a type nothing covers yet.

Nothing here is written by hand, so the pages follow whatever a pack changes. A mod's page only
appears when that mod is installed.
