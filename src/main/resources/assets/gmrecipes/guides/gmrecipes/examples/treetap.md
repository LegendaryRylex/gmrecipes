# Tree Tap

Tapping a log with a tap yields a bucket of sap. Each Tree Tapping recipe shows the log, or log tag, that is tapped, the bucket it fills (with the wooden and ceramic bucket variants cycling in the same slot), the tapping time and, for trees that need a minimum size, the number of logs required.
