# Iron's Spells 'n Spellbooks

The Alchemist Cauldron recipes. Brewing shows the reagent and the base fluid going in, with the resulting fluids and any byproduct item coming out. Bottling shows the container item and the fluid it draws, with the filled item. Filling shows the item poured in, with the fluid it adds and the container it returns.
